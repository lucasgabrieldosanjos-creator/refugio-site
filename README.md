# O Refúgio · imagens do site

Imagens e dados estáticos usados pelo site do servidor O Refúgio (ATM10), hospedado na CentralCart.
Servidos pelo jsDelivr: `https://cdn.jsdelivr.net/gh/lucasgabrieldosanjos-creator/refugio-site@main/...`

- `img/` artes do site (topo, logo, pilares, guildas, votação, tutorial)
- `itens/` ícones da interface
- `kit/` ícones dos itens dos kits
- `ranks/` brasões dos VIPs
- `kits.js` conteúdo dos kits (FonoKits)
- `site.js` script do site · `config.json` IP, versão do modpack, links e votação
