Muitos destes comandos são benefícios de VIP, e cada VIP libera um conjunto diferente. A tabela abaixo mostra quem tem cada um, e a [comparação de VIPs](#vips) tem a lista completa.

## Recursos portáteis

Bancada, bigorna, tear e os outros blocos portáteis funcionam como os blocos de verdade, inclusive no custo de experiência.

## Phantoms

`/phantom off` faz os phantoms pararem de aparecer para você (para os outros jogadores, nada muda). Use `/phantom status` para conferir.

## Skins e capas

`/capa listar` mostra o catálogo e `/capa usar <id>` aplica uma capa. Se der erro ao aplicar, [abra um ticket no Discord](https://discord.gg/cM8F5sTetW).

| Comando | Para que serve |
|---|---|
| `/kit <nome>` | Resgatar um kit disponível. |
| `/kits` | Listar seus kits. |
| `/luz` | Alternar visão noturna no personagem. **Todos os VIPs.** |
| `/ping` | Consultar sua latência. |
| `/list` | Listar jogadores visíveis para você. |
| `/seen <jogador>` | Consultar o último registro de presença permitido. |
| `/near [raio]` | Consultar jogadores próximos conforme limites. **VIP Arquiteto, Runista ou superior.** |
| `/hat` | Usar o item da mão como chapéu, quando aceito. **Todos os VIPs.** |
| `/repair` | Reparar o item aceito pelo comando. **VIP Arconte, Ascendente ou superior.** |
| `/repair all` | Reparar itens elegíveis do inventário. **ATM Major.** |
| `/feed` | Recuperar alimentação conforme as regras. **VIP Arconte, Ascendente ou superior.** |
| `/ext` | Apagar o fogo do seu personagem. |
| `/fly [on/off]` | Alternar voo autorizado. **VIP Cientista, Arconte, Ascendente, ATM Major e Construtor.** |
| `/workbench` | Abrir bancada portátil. **VIP Arquiteto, Runista ou superior.** |
| `/anvil` | Abrir bigorna portátil. **VIP Arconte, Ascendente ou superior.** |
| `/grindstone` | Abrir rebolo portátil. **ATM Major.** |
| `/loom` | Abrir tear portátil. **ATM Major.** |
| `/cartography` | Abrir mesa de cartografia portátil. |
| `/smithing` | Abrir mesa de ferraria portátil. **ATM Major.** |
| `/stonecutter` | Abrir cortador de pedras portátil. **ATM Major.** |
| `/enderchest` | Abrir seu Ender Chest. **VIP Arquiteto, Runista ou superior.** |
| `/disposal` | Abrir o descarte de itens. **Todos os VIPs e Comerciante.** |
| `/suicide` | Encerrar a vida do personagem; efeitos de morte se aplicam. |
| `/phantom` | Ver ajuda do recurso. **Todos os VIPs.** |
| `/phantom on` | Habilitar sua preferência de phantoms. |
| `/phantom off` | Desabilitar sua preferência de phantoms. |
| `/phantom toggle` | Alternar a preferência. |
| `/phantom status` | Consultar sua preferência atual. |
| `/capa` | Abrir a listagem de capas disponíveis. |
| `/capa listar` | Listar o catálogo de capas. |
| `/capa usar <id>` | Solicitar a aplicação de uma capa do catálogo. |
| `/capa remover` | Solicitar remoção da capa aplicada. |
| `/skin` | Consultar seu visual atual. |
| `/skin list` | Consultar as skins cadastradas. |
| `/skin reset` | Restaurar o visual conforme o provedor instalado. |
