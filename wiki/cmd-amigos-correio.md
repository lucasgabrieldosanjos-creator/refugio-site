Use os menus para consultar progresso e recompensas antes de confirmar uma ação.

## Enviar um presente pelo correio

1. Segure o item na mão principal.
2. Use `/correio item Lucas Um presente para sua base!`.
3. Confira o destinatário, a mensagem e o item na confirmação.
4. Confirme sem trocar o item da mão.

`/correio mensagem Lucas Olá!` envia apenas texto, mesmo que você esteja segurando um item. Já `/correio enviar` pode preparar um envio com o item da mão. Se quiser enviar só texto, use a forma explícita **mensagem**.

Dá para mandar correio para quem está offline, desde que a pessoa já tenha entrado no servidor. Se aparecer um código de envio pendente, guarde o código e [abra um ticket no Discord](https://discord.gg/cM8F5sTetW) antes de tentar de novo.

## Missões

Abra `/missoes`, escolha a categoria e o objetivo. Confira os requisitos e o estado da recompensa. A entrega automática depende da missão; quando houver botão de resgate, use-o.

Se uma recompensa ficar pendente, não tente resgatar várias vezes: [abra um ticket no Discord](https://discord.gg/cM8F5sTetW) com o ID da missão e o seu nome real.

## Indicações

Antes de registrar uma referência, confirme quem indicou você e confira as regras exibidas. A referência pode ter limites de alteração e requisitos de tempo.

| Comando | Para que serve |
|---|---|
| `/amigos` ou `/friends` | Abrir o menu de amizades. |
| `/amigos add <jogador>` ou `/amigos adicionar <jogador>` | Enviar pedido de amizade. |
| `/amigos accept <jogador>` ou `/amigos aceitar <jogador>` | Aceitar um pedido de amizade. |
| `/amigos deny <jogador>` ou `/amigos recusar <jogador>` | Recusar um pedido. |
| `/amigos remove <jogador>` ou `/amigos remover <jogador>` | Remover uma amizade. |
| `/amigos list` ou `/amigos listar` | Listar amigos. |
| `/amigos pedidos` | Ver os pedidos recebidos. |
| `/correio` | Abrir a caixa de entrada. |
| `/correio menu` | Abrir o menu do correio. |
| `/correio mensagem <jogador> [texto]` | Enviar apenas um recado. |
| `/correio item <jogador> [texto]` | Preparar envio do item da mão. |
| `/correio enviar <jogador> [texto]` ou `/correio send <jogador> [texto]` | Enviar texto ou preparar anexo da mão. |
| `/missoes` ou `/missions` | Abrir o navegador de missões. |
| `/recompensas` ou `/rewards` | Abrir recompensas configuradas. |
| `/referencia` ou `/ref` ou `/referrals` | Abrir o painel de indicações. |
| `/referencia set <jogador>` | Registrar sua referência conforme as regras. |
