O menu reúne os principais sistemas do Refúgio. Comece por ele e use os atalhos quando já souber onde quer chegar.

## Como ler os comandos

- `<jogador>` e `<valor>` são campos que você substitui. Não digite os sinais de maior e menor.
- Um campo entre colchetes é opcional: `[nome]`.
- A barra separa opções nas explicações; execute uma de cada vez.
- Pressione **Tab** para ver opções válidas. Alguns comandos desaparecem quando falta permissão.

> [!IMPORTANTE]
> **Conta real e apelido:** use o nome real no cadastro, login, votações e vinculação com o Discord. O apelido é uma apresentação do personagem, não outra conta.

## Primeiro acesso

Quando o servidor pedir cadastro, use uma senha exclusiva. Depois, faça a vinculação solicitada pelo FonoBot no Discord. Nunca coloque sua senha em um canal público do Discord. Só execute os comandos de autenticação quando o próprio servidor pedir.

Os atalhos do menu só mostram o que a sua conta já tem. Eles não liberam benefícios de VIP.

| Comando | Para que serve |
|---|---|
| `/register <senha> <confirmacao>` | Cadastrar a senha, quando solicitado pelo servidor. |
| `/login <senha>` | Autenticar sua conta. |
| `/ajuda` | Abrir a ajuda configurada no servidor. |
| `/ajuda <tema>` | Consultar um assunto da ajuda; use Tab para os temas disponíveis. |
| `/menu` ou `/community` | Abrir o menu principal. |
| `/menu amigos` | Abrir o painel de amizades. |
| `/menu warps` | Ver destinos públicos. |
| `/menu kits` | Ver os kits disponíveis para sua conta. |
| `/menu correio` | Abrir sua caixa de correio. |
| `/menu lojas` | Abrir a lista de lojas cadastradas. |
| `/menu missoes` | Abrir categorias de missões. |
| `/menu recompensas` | Ver as recompensas configuradas. |
| `/menu referencia` | Abrir o sistema de indicações. |
| `/menu cashshop` | Abrir categorias da loja de Cash. |
| `/menu cash` | Abrir o painel de Cash. |
| `/menu servicos` | Abrir o menu de serviços. |
