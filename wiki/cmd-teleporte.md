Salve sua base com /sethome e combine os teleportes com outros jogadores antes de aceitar pedidos.

## Salvar e visitar uma casa

1. Vá ao ponto seguro que deseja salvar.
2. Execute `/sethome base`.
3. Confira sua lista em `/homes`.
4. Use `/home base` quando quiser voltar.

O número de casas depende do seu plano: de 10 a 50 com VIP (veja a [tabela de VIPs](#vips)). Se você se mexer ou entrar em combate durante a contagem, o teleporte é cancelado.

## Pedidos de teleporte

`/tpa Lucas` pede para **você ir até Lucas**. `/tpahere Lucas` pede para **Lucas vir até você**. O destinatário precisa aceitar. Confira quem enviou o pedido antes de usar `/tpaccept`.

> [!DICA]
> Com VIP, o teleporte é instantâneo, sem tempo de espera, e você ainda tem o `/back` para voltar ao último local. O `/back` não recupera itens.

| Comando | Para que serve |
|---|---|
| `/spawn` | Voltar ao spawn. |
| `/sethome [nome]` | Salvar uma casa; sem nome usa home. |
| `/home [nome]` | Teleportar para uma casa. |
| `/homes` | Consultar as casas salvas. |
| `/homes pagina <pagina>` | Consultar outra página de suas casas. |
| `/delhome <nome>` | Apagar a casa indicada. |
| `/warps` | Listar warps públicos. |
| `/warp <nome>` | Ir ao warp indicado. |
| `/tpa <jogador>` | Pedir para ir até outro jogador. |
| `/tpahere <jogador>` | Pedir que outro jogador venha até você. |
| `/tpaccept [jogador]` | Aceitar um pedido recebido; use o nome se necessário. |
| `/tpdeny [jogador]` | Recusar um pedido. |
| `/tpacancel [jogador]` | Cancelar um pedido enviado. |
| `/back` | Retornar ao local registrado pelo sistema. **Todos os VIPs.** |
| `/tpr` ou `/rtp` | Solicitar teleporte aleatório. |
| `/getpos` | Ver suas coordenadas. |
| `/depth` | Consultar a informação de profundidade/altura. **Todos os VIPs.** |
| `/compass` | Consultar a direção. **Todos os VIPs.** |
