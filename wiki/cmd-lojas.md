Há três recursos diferentes: o cadastro de um local comercial, as lojas de baú e a loja de Cash.

## Qual comando abre qual loja?

| Comando | Sistema |
|---|---|
| /lojas e /loja | Cadastro, visita e divulgação dos locais comerciais dos jogadores |
| /qs | Lojas de compra/venda ligadas a baús/inventários |
| /cashshop e /shop | Loja de produtos comprados com Cash |

### Cadastrar seu local

Vá ao ponto de chegada, use `/loja cadastrar Minha Loja`, confira `/loja info` e ajuste `/loja setspawn`. Use `/loja abrir` para liberar as visitas. Criar e anunciar loja própria é benefício de **todos os VIPs e do Comerciante**, e o cadastro tem validade: renove com `/loja renovar`.

### Criar uma loja de baú

Segure o item de referência, aponte para o inventário correto e use `/qs create 100`, por exemplo. O preço do exemplo é ilustrativo. Confira o painel, o item, a quantidade por pacote e o tipo da loja antes de negociar.

`/qs sell` significa que **a loja vende ao visitante**. `/qs buy` significa que **a loja compra do visitante**. Alguns ajustes exigem que você olhe para a loja e seja o proprietário.

### Vender fluidos

Abra `/fluidos` e escolha o modo. Use recipientes aceitos pelo sistema. O modo múltiplo é benefício VIP, e o VIP também aumenta o bônus de venda. Confira a oferta antes de confirmar.

### Crates e votação

Consulte as chaves em `/crates` e as recompensas de uma caixa em `/crates preview <id>`. A forja segue as receitas exibidas. Para votar, abra `/vote`, visite os sites e use seu nome real exato. Tudo sobre votos está no guia [Votação e recompensas](#wiki/votacao).

| Comando | Para que serve |
|---|---|
| `/lojas` ou `/shops` | Listar locais comerciais cadastrados. |
| `/loja` | Abrir o menu de locais comerciais. |
| `/loja cadastrar <nome>` ou `/loja create <nome>` | Cadastrar seu local comercial. |
| `/loja setspawn` | Definir o ponto de chegada da sua loja. |
| `/loja abrir` ou `/loja open` | Abrir o cadastro para visita. |
| `/loja fechar` ou `/loja close` | Fechar o cadastro para visita. |
| `/loja info` | Ver nome, proprietário, status, validade e spawn. |
| `/loja rename <nome>` | Renomear seu local. |
| `/loja renovar <periodo>` | Renovar a validade; exemplo: 30d. |
| `/loja extend <dias>` | Renovar usando quantidade de dias. |
| `/loja visitar <jogador>` | Visitar a loja do proprietário indicado. |
| `/loja tp <nome>` | Visitar pelo nome do cadastro. |
| `/loja anunciar <texto>` | Divulgar sua loja. |
| `/loja anunciar item [texto]` | Divulgar um item da mão com a loja. |
| `/qs` | Abrir a ajuda de lojas de baú. |
| `/qs browse [pagina]` | Navegar pelas lojas registradas. |
| `/qs view <id>` | Consultar os detalhes de uma loja. |
| `/qs create <preco>` | Criar loja que vende ao visitante. |
| `/qs sell [preco]` | Mudar para venda ou criar uma loja de venda. |
| `/qs buy [preco]` | Mudar para compra ou criar uma loja de compra. |
| `/qs amount <quantidade>` | Definir o tamanho do pacote da loja. |
| `/qs item` | Alterar o item de referência da loja. |
| `/qs price <preco>` | Alterar o preço da loja. |
| `/qs info` | Ver detalhes da loja apontada. |
| `/qs list` | Consultar suas lojas de baú. |
| `/qs remove` | Remover a loja apontada. |
| `/cashshop` ou `/shop` | Abrir a loja de Cash. |
| `/fluidos` | Abrir a seleção do modo de venda de fluidos. |
| `/fluidos unidade` ou `/fluidsell` | Abrir a venda de um recipiente. |
| `/fluidos multiplos` ou `/fluidsell bulk` | Abrir a venda de vários recipientes. |
| `/crates` ou `/crate` | Abrir a central de crates. |
| `/crates chaves` ou `/crates keys` | Consultar suas chaves na central. |
| `/crates preview <id>` | Consultar a prévia de uma crate. |
| `/crates forja` ou `/crates forge` | Abrir a forja de chaves. |
| `/crates help` | Ver a ajuda do sistema. |
| `/vote` | Abrir os sites de votação. |
| `/vote stats` | Ver seu total de votos registrado. |
| `/vote top` | Consultar o ranking de votos. |
